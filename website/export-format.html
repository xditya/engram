Export format

Settings → Export writes one zip. Everything in it is plain: JSON, CSV, markdown and your original files. Nothing needs engram to open, and this page is the contract: a test in the repo fails if the layout changes.

engram-export-2026-08-27.zip
├─ engram.json  everything, for importing back into engram
├─ cards.csv  one row per card, opens in any spreadsheet
├─ notes/  one markdown file per card, Obsidian-ready
│   └─ sourdough-bread-01a0343f.md
└─ files/  your originals, named by content hash
    └─ 9f2c…e1a4.jpg

engram.json

The full library, column for column, in one object. Importing it into another engram restores cards, tags, Spaces and file references (files come from files/).

{
  "engram": 1, format version
  "exportedAt": 1787000000000, ms since epoch
  "items": [ { id, type, url, domain, title, body, summary, ocr_text, meta, colors,
              embedding, embedding_dim, embedding_model, pinned_at, opened_at, open_count,
              resurfaced_at, let_go_at, deleted_at, created_at, updated_at, created_by } ],
  "tags": [ { item_id, tag, source, deleted_at } ], source: user | ai | import
  "spaces": [ { id, name, query, sort, deleted_at } ],
  "spaceItems": [ { space_id, item_id, added_at, deleted_at } ],
  "files": [ { hash, item_id, role, mime, bytes, w, h, blurhash, deleted_at } ] role: original | thumb | poster | reader_html
}

type is one of note, link, article, image, video, pdf, quote, product, book, recipe, tweet, repo, file. meta is a JSON string of per-type extras (price, author, duration, shortcode…). embedding is base64 of little-endian float32; everything else is a plain value or null. Times are milliseconds since the epoch. Cards you let go keep a deleted_at and are still in the file.

cards.csv

UTF-8, comma separated, quoted where needed, one header row. Cards you let go are left out.

id, type, title, url, domain, body, summary, tags, ai_tags, created, updated

tags holds tags you added or imported, ai_tags the ones engram added, both comma separated inside the cell. created and updated are ISO 8601.

notes/*.md

One file per card, named <title-slug>-<first 8 of id>.md. YAML front matter, then the card's text as the body. Drop the folder into an Obsidian vault and tags become Obsidian tags.

---
id: 01a0343f-…
type: article
created: 2026-08-25T10:12:03.000Z
title: "Sourdough bread"
url: "https://kingarthur.com/…"
summary: "…"
tags: ["baking", "food"]
---
Flour, water, salt…

files/

Your originals (photos, PDFs, videos), the thumbnails engram made, and saved reader copies of articles (.html). Each is named by the BLAKE3 hash of its bytes plus an extension from its type, and files in engram.json maps every hash to its card and role.

Coming back

Settings → Import accepts the whole zip and restores everything, including which Space each card sat on. It also reads a mymind export, Raindrop and Pocket CSVs, browser bookmark HTML, and a folder of markdown files.
